# 道医苏子阳抽取契约（v3 · 宁缺毋滥）

给抽取子代理。先读完再写。输出必须能直接入白草图谱。

白草是中医药**可信知识图谱**，不是小说摘要、不是功法百科、不是把章里出现过的词都做成节点。

## 0. 本波目标

从叙事文本里抽出**可入图、可追溯、可复核**的临床知识：医案、方剂组成、穴位施用、炮制、明确病证。

**宁缺毋滥。** 拿不准就 skip。少抽对的，好过多抽脏的。

v1 失败：方剂标成药材、书名标成证据、边大量缺失。  
v2 失败：信封过关，但灌水医案、方剂无组成、治法混进武术/诊法/理论、空类病证。v2 已从 Neo4j 回滚。

不要再犯这些。

## 1. 只交这一个文件

只写分配给你的 JSONL。不要改别的文件。每行一条节点。`edges` 必须是数组。不要 markdown 围栏。

输出路径：`datasets/baicao-knowledge/sources/daoyi-suyang/work/extracts-v3/batch-XX.jsonl`  
`batch_id`：`2026-08-16-suyang-v3-bXX`（XX 与批次号一致，不要用 v2 / 旧 b01）

## 2. 什么才算知识（过这关才抽）

一章**至少**满足下面一条，才抽知识节点；否则整章 skip。

| 可抽 | 必须同时具备 |
|------|----------------|
| 医案 | 有具体患者（或明确复诊对象）+ 具体病证/主诉 + **实际干预**（开方 / 扎针取穴 / 施用治法） |
| 方剂 | 原文给出方名，且（用于上述医案，**或**列出组成药味）。有剂量必须抽出全部组成 |
| 穴位 | 原文写明在本次诊疗中取用，不是功法课点到穴名 |
| 炮制/工艺 | 针对药材的加工方法（水飞、盐制、烊化、煎法），不是兵器/夹板/采药故事 |
| 药材/饮片 | 作为方剂组成、单味用药、或炮制对象出现 |
| 病证 | 具体证名或病名，来自本次诊疗或该方主治 |
| 功效/性味/归经 | **原文明确写出**，禁止脑补 |

## 3. 必须整章 skip（只写 1 条来源）

通篇是下面这些，**即使出现“病/痛/汤/针”字样**：

- 路途、聚会、婚礼、求婚、吃饭、吵架、拜师情节
- 锦旗回访、痊愈道谢、没有新处方/新针法
- 武术训练、点穴对打、铁布衫/金钟罩/八卦掌/字门拳
- 内丹、筑基、大周天、炼气，但没有患者
- 五运六气、脉学闲谈、诊法理论课，但没有患者和完整方剂
- 香火大仙、骗局、江湖规矩
- 人物简介、出生、同学、回家过年

skip 形态：

```json
{"source_id":"daoyi-suyang","batch_id":"2026-08-16-suyang-v3-b01","unit_id":"chapter-001","unit_title":"第1章 苏子阳","processor":"composer-2.5-subagent","extracted_at":"2026-08-16T18:00:00+00:00","node_type":"来源","node_name":"道医苏子阳","source":"daoyi-suyang","status":"pending","evidence_refs":[],"evidence_text":"","properties":{"import_source_id":"daoyi-suyang","import_batch_id":"2026-08-16-suyang-v3-b01","import_unit_id":"chapter-001","skip_reason":"no_clinical_knowledge"},"edges":[]}
```

skip 章**禁止**再写医案/病证/治法。高 skip 率是预期，不是失败。

## 4. 节点怎么用

| 类型 | 用在 | 不要用在 |
|------|------|----------|
| 医案 | 名=`医案:{unit_id}`，仅真实诊疗事件 | 简介、理论课、练功、回访道谢 |
| 方剂 | 止嗽散、小青龙汤、六味地黄丸、院内经验方 | 骨头汤、黄精排骨等食谱（除非原文当处方且有药味剂量） |
| 药材 | 单味：桔梗、荆芥、干姜 | 方名、穴位、功法 |
| 饮片 | 艾绒、盐附子、黑顺片、炮附子 | 未炮制的原药材；不要标成工艺 |
| 穴位 | 廉泉、太溪、下关。统一**不加**「穴」后缀 | 肺经大穴；功法点穴演示 |
| 治法 | 本次用在患者身上的治疗手段：烧山火、飞腾八法、祝由、热盐熨烫、小儿推拿、放血 | 手诊/脉诊/望诊、五运六气、铁布衫、认药、服药时机、说破不灵骗术 |
| 工艺 | 水飞、盐制、烊化、三上三下煎油 | 采药、禹步、节气、夹板（裹帘/通木）、吐纳 |
| 病证 | 风寒咳嗽、恶露不净、淋证、鬼交 | 内科杂病、疑难杂症、各种痛症、杂病 |
| 功效 | 原文写明的功用 | 自己总结 |
| 性味 / 归经 | 原文明确写出 | 不要猜；石膏不是性味 |
| 来源 | `道医苏子阳`；被引用的书名《伤寒论》 | 张仲景序、歌诀名，除非它本身是文献 |
| 证据 | 名=`证据:daoyi-suyang:{unit_id}` | 书名、方名、章号 |

## 5. 边怎么用

知识节点（医案/方剂/药材/饮片/穴位/治法/病证/功效/性味/归经/工艺，以及非 skip 的来源书）**必须**同时有：

- `来源于` → `道医苏子阳`
- `由证据支持` → `证据:daoyi-suyang:{unit_id}`

临床结构：

```
医案:{unit_id} -治疗病证→ 风寒咳嗽
医案:{unit_id} -使用方剂→ 止嗽散
医案:{unit_id} -取用穴位→ 太溪
医案:{unit_id} -采用治法→ 烧山火
病证 -记载于医案→ 医案:{unit_id}
方剂 -组成药材→ 桔梗     （properties.dosage 用原文剂量）
方剂 -治疗病证→ 风寒咳嗽
方剂 -具有功效→ 止咳化痰
药材 -经过工艺→ 水飞
```

硬性：

- `edges[].target` 必须是**本文件里已经作为 node_name 出现的节点**。先写被指向的节点。
- **禁止** `病证 -治疗病证→ *`。`治疗病证` 只从 医案/方剂/药材/治法 指出。
- **禁止** 医案 `记载于医案` 指向自己。
- `采用治法` 的 target 必须是 `治法` 节点，不能是 `工艺`。
- `经过工艺` 的 target 必须是 `工艺` 节点，不能是饮片/方剂/药材。
- `使用方剂` 的 target 必须是 `方剂`。
- `组成药材` 的 target 必须是 `药材` 或 `饮片`。
- 有医案就必须有 `治疗病证`，并且至少有 `使用方剂` / `取用穴位` / `采用治法` 之一。缺干预就不要造医案。
- 原文列出药味（含 `12g` / `四钱` 等）时，方剂**必须**为每一味建 `药材`/`饮片` 节点和 `组成药材` 边。漏一味算失败。禁止只抽前两味。
- 原文只提方名、无组成、也未用于医案 → **不要抽这个方**。
- 同一 `(unit_id, node_type, node_name)` 只写一行。

## 6. 证据与来源

有知识时每章固定：

```json
{"node_type":"来源","node_name":"道医苏子阳","edges":[]}
{"node_type":"证据","node_name":"证据:daoyi-suyang:chapter-002","evidence_text":"原文短摘≤80字","evidence_refs":[],"edges":[{"type":"来源于","target":"道医苏子阳","properties":{}}]}
```

其它知识节点的 `evidence_refs` 填 `["证据:daoyi-suyang:chapter-002"]`。`evidence_text` 用原文短摘，≤80 字，不要改写成长摘要。
