## 2. MVP 功能清单

### 2.1 MVP Scope

**目标**: 在首个版本中验证核心价值 - "可溯源的知识图谱问答"

#### 核心功能 (Must Have)

1. **智能问答**
   - 自然语言问答
   - 答案展示与实体高亮
   - 基础上下文理解

2. **溯源链路展示**
   - 证据列表展示
   - 来源跳转
   - 证据摘要显示

3. **知识图谱可视化**
   - 基础图谱渲染
   - 节点点击查看
   - 关系类型展示

4. **药材详情页**
   - 基本信息展示
   - 功效/主治/用法
   - 关联证据标识

5. **专家审查工作台**
   - 审查任务列表
   - 审查操作 (批准/修正/驳回)
   - 审查历史记录

6. **搜索功能**
   - 药材名称搜索
   - 实时建议
   - 搜索结果展示

### 2.2 Out of Scope (MVP)

- 高级筛选
- 追问延续
- 图谱路径探索
- 审查通知
- 证据关联网络
- 移动端适配

## 3. Release Planning

### 3.1 Release 1: MVP (Sprint 1-4)

**目标**: 验证核心问答与溯源价值

| Sprint | 内容 | 交付物 |
|--------|------|--------|
| Sprint 1 | 基础问答框架、图谱数据模型 | 问答API、基础图谱存储 |
| Sprint 2 | 智能问答实现、溯源展示 | 问答界面、溯源链路组件 |
| Sprint 3 | 图谱可视化、药材详情 | 图谱浏览器、详情页 |
| Sprint 4 | 专家审查、搜索功能 | 审查工作台、搜索组件 |

**验收标准**:
- 问答响应时间 < 2秒
- 溯源覆盖率 > 95%
- 专家审查流程闭环完成

### 3.2 Release 2: 体验增强 (Sprint 5-6)

**目标**: 提升用户互动深度

| Sprint | 内容 | 交付物 |
|--------|------|--------|
| Sprint 5 | 追问延续、路径探索 | 对话上下文、高级图谱 |
| Sprint 6 | 高级筛选、通知系统 | 筛选器、消息通知 |

**验收标准**:
- 追问理解准确率 > 85%
- 图谱探索使用率 > 20%

### 3.3 Release 3: 规模化 (Sprint 7-8)

**目标**: 支持更多用户与机构

| Sprint | 内容 | 交付物 |
|--------|------|--------|
| Sprint 7 | 机构用户、权限管理 | 机构管理、角色权限 |
| Sprint 8 | 性能优化、监控告警 | 性能达标、SLA保障 |

## 5. 依赖关系

### 5.1 功能依赖图

```
智能问答
    │
    ├──► 溯源展示
    │       │
    │       └──► 来源跳转
    │
    ├──► 图谱可视化
    │       │
    │       ├──► 药材详情页
    │       │
    │       └──► 路径探索
    │
    └──► 专家审查
            │
            └──► 审查通知
```

### 5.2 技术依赖

| 功能 | 前置依赖 | 说明 |
|------|---------|------|
| 智能问答 | 图谱数据模型 | 需先完成Schema设计 |
| 溯源展示 | 智能问答 | 答案生成后才能溯源 |
| 图谱可视化 | 图谱数据模型 | 需先完成数据存储 |
| 专家审查 | 问答+溯源 | 需先有可审查内容 |
| 搜索功能 | 药材详情页 | 需先有数据展示 |

## 6. 风险与缓解

| 风险 | 影响 | 概率 | 缓解措施 |
|------|------|------|---------|
| 图谱数据质量不足 | 高 | 中 | 预设种子数据，迭代补充 |
| 问答准确率不达标 | 高 | 中 | 专家参与Prompt优化 |
| 专家审查响应慢 | 中 | 高 | 设置SLA，激励机制 |
| 图谱渲染性能 | 中 | 中 | 分级加载，懒加载策略 |
| 用户采用率低 | 高 | 中 | 早期用户测试，快速迭代 |
