# System Architect Context

## 技术约束与决策

| 问题 | 回答 | 说明 |
|------|------|------|
| 技术栈偏好 | Python FastAPI + React | 已有项目结构 |
| 部署环境 | 私有服务器 | 自托管 |
| 外部集成 | 无 | 独立系统 |
| 用户规模 | 无明确预期 | 初期小规模 |
| 数据规模 | 万级实体 | Neo4j + PostgreSQL |
| 服务拆分 | Modular Monolith | 模块化单体 |
| 通信模式 | Event-Driven | 事件驱动 |

## 架构决策上下文

- **模块化单体**: 保持单体架构的简单性，但按领域模块化拆分
- **事件驱动**: 用于解耦知识更新、审查通知等异步流程
- **万级实体**: 数据规模适中，需关注图查询性能
- **私有部署**: 自运维，需考虑监控和日志
